🚀 为什么不需要后端？如何传到 GitHub？

个人展示与换装交互的所有状态、3D 渲染、UI 音效与语音都在访客浏览器本地运行，完全不需要购买云服务器或搭建后端数据库。

  1. 在 GitHub 新建一个公开仓库（如 my-3d-space 或 你的用户名.github.io）。
  2. 将本项目的 index.html（以及可选的 assets/ 录音或模型文件）上传到仓库根目录。
  3. 进入仓库 Settings → Pages，Source 选择 main 分支保存，1 分钟后即可获得全球可访问的 HTTPS 个人网站链接！
